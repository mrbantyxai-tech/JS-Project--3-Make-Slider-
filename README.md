🚗 Car Image Slider | HTML, CSS & JavaScript

A modern and responsive Car Image Slider built using HTML5, CSS3, and Vanilla JavaScript. This project demonstrates smooth slide animations, interactive navigation, and a clean automotive-inspired UI without using any external libraries or frameworks.

✨ Features
🚘 Smooth slide transition using CSS transform
⬅️ Previous & Next navigation buttons
🔄 Infinite looping slider
🎯 Interactive navigation dots
🖱️ Clickable car cards for direct slide navigation
🎨 Modern dark-themed automotive interface
📱 Responsive layout for desktop and mobile devices
⚡ Built entirely with Vanilla JavaScript

⚙️ How It Works
Each slide is arranged horizontally inside a slider container.
JavaScript maintains the current slide index.
Clicking Next or Previous updates the active slide.
CSS transform: translateX() creates the smooth sliding animation.
Navigation dots and car cards automatically update to match the current slide.
The slider loops seamlessly from the last slide back to the first.
